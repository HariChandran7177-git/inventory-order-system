# 📡 REST API Technical Specification

This document provides complete schema references, request/response models, query parameters, and error status codes for both microservices in the **Inventory Order System**.

Interactive Swagger / OpenAPI interfaces are available at:
- **Inventory Service:** `http://localhost:8000/docs`
- **Payment Service:** `http://localhost:8001/docs`

---

## 1. Inventory Service (Port 8000)

### 1.1 Health Probe
- **Endpoint:** `GET /health`
- **Response:** `200 OK`
```json
{
  "status": "ok",
  "service": "inventory"
}
```

---

### 1.2 List All Products
- **Endpoint:** `GET /inventory/products`
- **Query Parameters:**
  - `category` *(optional, string)*: Filter products by category name.
- **Cache Policy:** FastAPICache (600s TTL, Cache-Aside)
- **Response:** `200 OK`
```json
[
  {
    "id": "01JBMX9Q3Y4ABCDEF123456789",
    "name": "Wireless Mechanical Keyboard",
    "price": 120.0,
    "quantity": 15,
    "category": "Electronics",
    "creation_time": 1710000000
  }
]
```

---

### 1.3 Get Single Product
- **Endpoint:** `GET /inventory/product/{pk}`
- **Path Parameters:**
  - `pk` *(required, string)*: Product primary key generated by Redis OM.
- **Cache Policy:** FastAPICache (`inventory.product:{pk}`)
- **Responses:**
  - `200 OK`: Product object.
  - `404 Not Found`:
    ```json
    {
      "detail": "Product with pk '01JBM...' not found"
    }
    ```

---

### 1.4 Create Product
- **Endpoint:** `POST /inventory/product`
- **Cache Invalidation:** Clears `inventory.products` cache.
- **Request Body:**
```json
{
  "name": "Noise Cancelling Headphones",
  "price": 199.99,
  "quantity": 25,
  "category": "Audio"
}
```
- **Validation Rules:**
  - `name`: String, 1–120 characters, non-blank.
  - `price`: Float, $\ge 0.0$.
  - `quantity`: Integer, $\ge 0$.
  - `category`: String *(optional)*.
- **Responses:**
  - `200 OK`: Created product including generated `pk` and `creation_time`.
  - `422 Unprocessable Entity`: Request body validation failed.

---

### 1.5 Update Product
- **Endpoint:** `PUT /inventory/product/{pk}`
- **Cache Invalidation:** Clears item cache and list cache.
- **Request Body:** Subset of `name`, `price`, `quantity`, `category`.
```json
{
  "price": 179.99,
  "quantity": 30
}
```
- **Responses:**
  - `200 OK`: Updated product record.
  - `404 Not Found`: Product not found.
  - `422 Unprocessable Entity`: Invalid negative price or quantity.

---

### 1.6 Delete Product
- **Endpoint:** `DELETE /inventory/product/{pk}`
- **Cache Invalidation:** Clears item cache and list cache.
- **Responses:**
  - `200 OK`: Confirmation of deleted product.
  - `404 Not Found`: Product not found.

---

## 2. Payment Service (Port 8001)

### 2.1 Health Probe
- **Endpoint:** `GET /health`
- **Response:** `200 OK`
```json
{
  "status": "ok",
  "service": "payment"
}
```

---

### 2.2 Pre-Payment Checkout Validation
- **Endpoint:** `POST /orders/validate`
- **Description:** Pre-payment validation gate between Step 1 (Review) and Step 2 (Payment). Validates all cart items against live inventory for stock sufficiency and price fluctuations (price hike or price drop).
- **Request Body:**
```json
{
  "items": [
    {
      "product_id": "01JBMX9Q3Y4ABCDEF123456789",
      "order_quantity": 2,
      "client_price": 100.0
    }
  ]
}
```
- **Response:** `200 OK`
```json
{
  "is_valid": true,
  "has_stock_issues": false,
  "has_price_changes": false,
  "items": [
    {
      "product_id": "01JBMX9Q3Y4ABCDEF123456789",
      "name": "Wireless Mechanical Keyboard",
      "requested_quantity": 2,
      "available_stock": 10,
      "has_sufficient_stock": true,
      "client_price": 100.0,
      "current_price": 100.0,
      "price_difference": 0.0,
      "price_change_type": "none",
      "status": "ok"
    }
  ],
  "updated_subtotal": 200.0,
  "updated_platform_fee": 3.0,
  "updated_total": 203.0
}
```
*(If stock is insufficient, `has_sufficient_stock: false` and `status: "insufficient_stock"`. If price changed, `price_change_type: "hike"` or `"drop"` with the delta `price_difference`).*

---

### 2.3 List Orders
- **Endpoint:** `GET /orders/`
- **Response:** `200 OK` (Array of SQLModel orders sorted by `order_id` descending)
```json
[
  {
    "order_id": 1,
    "product_id": "01JBMX9Q3Y4ABCDEF123456789",
    "price": 100.0,
    "fee_per_unit": 1.5,
    "total": 203.0,
    "order_quantity": 2,
    "status": "pending",
    "created_at": "2026-11-14T10:30:00"
  }
]
```

---

### 2.3 Get Order by ID
- **Endpoint:** `GET /orders/{order_id}`
- **Responses:**
  - `200 OK`: Order record.
  - `404 Not Found`: Order not found.

---

### 2.4 Place New Order
- **Endpoint:** `POST /orders/`
- **Request Body:**
```json
{
  "product_id": "01JBMX9Q3Y4ABCDEF123456789",
  "order_quantity": 2
}
```

#### Order Processing Flow:
1. Calls `GET http://localhost:8000/inventory/product/{product_id}` to validate current stock and price.
2. Computes platform fee at **1.5%** of the shelf price (which includes 5% GST):
   $$\text{fee\_per\_unit} = \text{round}(0.015 \times \text{unit\_price}, 2)$$
   $$\text{total} = \text{round}((\text{unit\_price} + \text{fee\_per\_unit}) \times \text{order\_quantity}, 2)$$
3. Inserts order into PostgreSQL with `status = 'pending'`.
4. Publishes `order_completed` event to Redis Streams.
5. Returns order record to client.

#### Status Codes:
- `200 OK`: Order placed and registered in `pending` state.
- `400 Bad Request`: Requested quantity exceeds available inventory stock.
- `404 Not Found`: Product ID not found in Inventory Service.
- `422 Unprocessable Entity`: Invalid quantity $\le 0$ or missing fields.
- `502 Bad Gateway`: Inventory Service is unreachable or returned invalid data.

---

### 2.5 Update Order
- **Endpoint:** `PUT /orders/{order_id}`
- **Request Body:** Subset of `status`, `total`, `order_quantity`.
- **Implementation:** Atomic SQL execution using `.returning(Order)`.
- **Responses:**
  - `200 OK`: Updated order record.
  - `404 Not Found`: Order not found.

---

### 2.6 Delete Order
- **Endpoint:** `DELETE /orders/{order_id}`
- **Responses:**
  - `200 OK`: Confirmation of deletion.
  - `404 Not Found`: Order not found.

---

## 3. Asynchronous Redis Streams Event Payloads

### 3.1 `order_completed` Stream
Published by Payment API when an order is registered:
```json
{
  "order_id": 101,
  "product_id": "01JBMX9Q3Y4ABCDEF123456789",
  "order_quantity": 2
}
```
*Consumer:* Inventory background worker (`inventory.app.workers.consumer`) executes `LUA_ATOMIC_DECREMENT`.

---

### 3.2 `refund_order` Stream
Published by Inventory Worker if downstream stock check discovers stock was depleted:
```json
{
  "order_id": 101
}
```
*Consumer:* Payment background worker (`payment.app.workers.consumer`) updates PostgreSQL order status to `refunded`.
